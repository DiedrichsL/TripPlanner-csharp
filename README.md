# TripPlanner – Application de planification de voyages en groupe

## Description

TripPlanner est une application web développée en C# permettant d’organiser des voyages en groupe et de faciliter la prise de décisions entre participants.

Les utilisateurs peuvent proposer des activités, voter pour leurs préférences et suivre les décisions retenues.

Ce projet a été réalisé dans le cadre de ma formation au Brevet fédéral d’informaticien (spécialisation développement).

---

## Fonctionnalités

- Gestion des utilisateurs
- Création de voyages
- Ajout de propositions
- Système de vote
- Gestion des participants
- Sélection de la proposition retenue
